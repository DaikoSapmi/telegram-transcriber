# 🚀 Hurtigstart

## Første gang:
```bash
cd telegram-transcriber
./setup.sh
cp .env.example .env
# Rediger .env med TELEGRAM_BOT_TOKEN og ALLOWED_USERS
./start.sh
```

## Hver gang etterpå:
```bash
cd telegram-transcriber
./start.sh
```

## Stoppe:
Trykk `Ctrl+C`

## Få Telegram ID:
Gå til @userinfobot på Telegram

## Få Bot Token:
Gå til @BotFather på Telegram → /newbot
